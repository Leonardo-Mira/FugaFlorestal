# FUGA FLORESTAL

## Sobre o projeto

FUGA FLORESTAL é um jogo 2D desenvolvido em Python utilizando a biblioteca Pygame.

O jogador controla um personagem que precisa atravessar uma floresta, desviando de obstáculos pelo caminho. O objetivo é sobreviver e alcançar a distância de 30 metros para vencer.

O projeto foi desenvolvido como atividade acadêmica do curso de Engenharia de Software.

## Tecnologias utilizadas

- Python
- Pygame
- PyCharm
- Git e GitHub

## Controles

| Tecla | Ação |
|---|---|
| Seta para cima / baixo | Navegar pelo menu |
| Enter | Confirmar opção |
| Espaço | Fazer o personagem pular |

Também é possível selecionar as opções do menu utilizando o mouse.

## Objetivo do jogo

- Desviar dos obstáculos encontrados pelo caminho.
- Evitar colisões com os objetos.
- Alcançar 30 metros para vencer.
- Caso colida com um obstáculo, ocorre Game Over.

Ao vencer ou perder, o jogador pode iniciar uma nova partida ou retornar ao menu principal.
